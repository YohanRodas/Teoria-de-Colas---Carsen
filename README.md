# Aplicación de Teoría de Colas — Grupo Carsen, S.A.

Sitio de presentación del proyecto final del curso **Investigación de Operaciones**,
Universidad Mariano Gálvez de Guatemala, Escuela de Ingeniería en Sistemas de
Información, Plan Fin de Semana. Guatemala, octubre de 2026.

El estudio analiza el área de ventas de Grupo Carsen, S.A. como un sistema de
líneas de espera **M/M/2** y presenta los indicadores obtenidos a partir de las
entrevistas al personal y del registro de tiempos de una jornada observada.

## Páginas

| Archivo | Contenido |
|---|---|
| `index.html` | El estudio: modelo, obtención de datos, indicadores, hallazgo, propuesta y conclusiones |
| `evidencia.html` | Fotografías del trabajo de campo |
| `integrantes.html` | Integrantes del grupo y empresa colaboradora |
| `estilo.css` | Hoja de estilos compartida por las tres páginas |
| `fotos/` | Imágenes del sitio |

## Publicar en GitHub Pages

1. Crear un repositorio y subir el contenido de esta carpeta a la raíz.
2. En el repositorio: **Settings → Pages**.
3. En *Source* elegir **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guardar. En uno o dos minutos el sitio queda en
   `https://<usuario>.github.io/<repositorio>/`.

No requiere compilación ni dependencias: son archivos estáticos.
